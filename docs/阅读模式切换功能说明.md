# 阅读模式切换功能说明

## 功能概述

已成功实现阅读模式切换功能，支持在正常阅读模式和摘要阅读模式之间切换。

### 2. 功能实现状态

所有核心功能已完整实现：

#### 核心组件
- ✅ **ReadModeManager**: 阅读模式管理器，负责模式切换和状态管理
- ✅ **AISummaryRepository**: AI摘要仓库，负责生成和缓存章节摘要
- ✅ **SummaryCache**: 摘要缓存实体，支持本地缓存
- ✅ **ModeSwitchButton**: 模式切换按钮组件

#### 数据库支持
- ✅ **SummaryCache** 实体类

- ✅ 数据库迁移脚本

#### 配置项
- ✅ **summaryRatio**: 摘要比例配置（默认30%）
- ✅ **aiApiKey**: AI服务API密钥配置

## 使用方式

### 1. 工具栏切换
- 在阅读界面工具栏上点击"摘要模式"按钮
- 按钮会显示当前模式状态（选中/未选中）
- 支持在正常模式和摘要模式之间快速切换

### 2. 模式说明
- **正常模式**: 显示完整的章节内容
- **摘要模式**: 显示AI生成的章节摘要，约为原文的30%长度

### 3. 智能缓存
- 摘要内容会自动缓存，避免重复生成
- 缓存有效期为7天
- 支持清除缓存功能

## 技术特性

### 1. AI支持
- 支持多种AI模型：GPT-3.5-turbo, GPT-4, 文心一言, 通义千问
- 当AI服务不可用时，自动降级到本地摘要算法
- 支持自定义API密钥和摘要比例

### 2. 性能优化
- 异步处理，不阻塞UI
- 智能缓存机制
- 支持预加载下一章摘要

### 3. 用户体验
- **动态图标**: 工具栏按钮图标根据当前模式自动切换
  - 正常模式：显示正常阅读图标 (`ic_read_mode_normal`)
  - 摘要模式：显示摘要模式图标 (`ic_read_mode_summary`)
- **状态反馈**: 按钮选中状态与图标同步更新
- 章节标题会显示模式标识（如"第一章（摘要）"）
- 支持朗读摘要内容
- 模式状态持久化保存

## 配置说明

### 1. AI大模型配置
在阅读设置中的"AI模型配置"分组中可以配置：

#### 基础配置
- **AI服务提供商**: 选择AI服务（文心一言、通义千问、OpenAI、本地算法）
- **AI模型**: 根据选择的提供商显示对应的模型列表
- **摘要比例**: 控制摘要长度占原文的百分比（10%-100%）

#### 文心一言配置
- **支持模型**: ERNIE-4.0-8K、ERNIE-3.5-8K、ERNIE-Lite-8K等
- **认证方式**: API Key 或 Access Key + Secret Key
- **API端点**: 支持自定义服务地址

#### 通义千问配置  
- **支持模型**: qwen-turbo、qwen-plus、qwen-max等
- **认证方式**: API Key
- **API端点**: 支持自定义服务地址

#### OpenAI配置
- **支持模型**: GPT-3.5-turbo、GPT-4、GPT-4o等
- **认证方式**: API Key
- **API端点**: 支持自定义服务地址

#### 高级配置
- **创造性**: 控制生成内容的随机性（0.0-2.0）
- **最大令牌数**: 限制生成内容的长度（100-4000）
- **请求超时**: API请求超时时间（10-120秒）
- **测试连接**: 验证AI服务配置是否正确

### 2. 缓存管理
- 自动清理过期缓存
- 支持手动清除章节缓存
- 支持清除所有摘要缓存

## 使用示例

### 配置文心一言
1. 进入"设置" → "阅读设置" → "AI模型配置"
2. 选择"AI服务提供商" → "文心一言 (百度)"
3. 选择"AI模型" → "ERNIE-3.5-8K"（推荐新手使用）
4. 选择"认证方式" → "API Key"
5. 输入从百度智能云获取的API Key
6. 点击"测试连接"验证配置
7. 调整"摘要比例"到合适的值（建议30%-50%）

### 配置通义千问
1. 选择"AI服务提供商" → "通义千问 (阿里)"
2. 选择"AI模型" → "qwen-turbo"（性价比高）
3. 输入从阿里云DashScope获取的API Key
4. 测试连接并调整参数

### 配置OpenAI
1. 选择"AI服务提供商" → "OpenAI"
2. 选择"AI模型" → "GPT-3.5-turbo"（成本较低）
3. 输入OpenAI API Key
4. 可自定义API端点（支持代理服务）

## 注意事项

1. **首次使用**: 需要配置对应AI服务的API密钥
2. **网络依赖**: AI摘要需要网络连接，离线时自动使用本地算法
3. **API费用**: 使用AI服务会产生费用，请注意控制使用量
4. **缓存空间**: 摘要缓存会占用一定存储空间，建议定期清理
5. **兼容性**: 功能向后兼容，不影响现有阅读体验
6. **隐私安全**: 章节内容会发送到AI服务，请注意隐私保护
